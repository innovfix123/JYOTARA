# APK147: introductory Ask trial

Implemented on 10 October 2026 after the user's approval to build the free-trial entry flow. This is a combined mobile/backend change. Existing APK146 does not display this offer; APK147 is required. Google Play publication remains deferred by the user.

## User flow

After verified phone login and primary birth-profile setup, an eligible account sees one welcome offer. Start free chat opens the existing Ask conversation with an available guide. Users can ask about the normal supported topics and select the normal chat languages. The trial does not change provider accuracy or safety rules.

The 60-second allowance begins after the first useful completed answer. Confirmed unavailable answers do not start it. Provider waiting time is excluded, and an answer accepted before expiry can finish. The app displays the free-trial countdown. The existing paid chat timer remains hidden.

When the trial finishes, the app automatically opens coin packages. A verified payment returns to the same guide/chat with a new paid billing session. No payment or queued paid question is submitted automatically. Leaving packages returns to free app features. The introductory offer also has an explicit free-features alternative.

The current catalog is unchanged: Ask 40 coins per started question-triggered minute, a new Matching result 15 coins, personal Explore readings 5 coins, and Daily free. The ₹25/40-coin pack has no new Matching or Explore bonus. AST200's separate starter-benefit proposal remains unapproved. Saved Matching results remain free to reopen pending the user's unanswered repeat-charge clarification.

## Server and privacy

Migration 0030 adds account-linked introductory-trial state for each wallet mode. Eligibility excludes accounts with a paid recharge or reserved/completed Ask usage. Skipping, activation, session/guide ownership and completion are stored on the server. Reinstalling or reopening the same account does not create another allowance. The server refuses new requests after expiry and retains safe recovery of previously accepted requests. Trial quotes and completed trial receipts use zero coins; the client does not silently accept a paid quote in a trial.

Deleting the phone account cascades to active trial records. This implementation does not retain a permanent phone-based anti-fraud record after deletion and does not claim to prevent delete-and-register-again abuse. Existing authentication, limits and owned-profile checks still apply.

Trial offer/start/end/verified-recharge events use the existing closed journey vocabulary. No new grant to retain question/reply content or send it to marketing measurement is added. Terms version 1.2 and Privacy dated 10 October describe the actual allowance, optional purchases and trial-state storage. The public static `/terms` copy was aligned with the running API; it previously served an older policy.
